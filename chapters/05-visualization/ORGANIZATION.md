# Chapter 05 Organization

## Chapter Role

Chapter 05 gives students a first practical framework for choosing, reading, and creating charts with pandas.

## Learning Objectives

Students should be able to:

1. Choose basic chart types for common business and management questions.
2. Create simple exploratory plots from pandas objects.
3. Interpret chart patterns, outliers, and comparisons carefully.
4. Customize chart labels, scales, colors, and styles to support communication.
5. Identify when a visualization may mislead an audience.

## Sequence

1. `0500-visualization.ipynb` - Landing
   - Chapter orientation, video, learning goals, flow, glossary, and slides.
2. `0501-pandas-vis.ipynb` - Pandas Plotting Basics
   - Visualization orientation, pandas `.plot()`, plotting method variants, Seaborn sample datasets, and quick plot previews.
3. `0502-pandas-chart-types.ipynb` - Pandas Chart Types
   - Line, histogram, scatter, bar, box, area, KDE, and hexbin plots for common management questions.
4. `0503-pandas-plot-styling.ipynb` - Pandas Plot Styling
   - Styles, color maps, marker size, and emphasis choices for clearer communication.
5. `assignments/index.ipynb` - Assignments
   - Preview
   - Lab
   - Homework
