# Chapter 04 Organization

## Chapter Role

Chapter 04 teaches students how to load, inspect, clean, and transform table-shaped data for management analysis.

## Learning Objectives

Students should be able to:

1. Explain the difference between a Series and a DataFrame.
2. Load a dataset into pandas.
3. Inspect rows, columns, labels, and data types.
4. Select and transform columns for analysis.
5. Detect and handle missing data.
6. Perform common data operations needed before visualization and statistical work.

## Exercise And Assignment Plan

- Preview: scored multiple-choice questions covering pandas vocabulary and table-reading habits.
- Section notebooks: each active content section includes at least one paired `thebe-interactive` exercise and adjacent `hide-input` solution cell.
- Lab: server-graded applied practice with table-shaped data, labeled values, missing values, filtering/sorting, and grouping.
- Homework: server-graded reinforcement with five scenario-based true/false concept checks and five coding questions covering the chapter's main technical practice.
