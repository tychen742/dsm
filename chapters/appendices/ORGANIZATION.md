# Appendices Organization

## Appendix Role

The appendices support the course with setup, tooling, and reference material that students may need throughout the semester.

## Learning Goals

Students should be able to:

1. Identify the tools needed for the course workflow.
2. Install or access the Python and Jupyter environment used by the book.
3. Use virtual environments at a basic operational level.
4. Navigate and run Jupyter notebooks.
5. Find quick-reference resources when working through assignments.

## Sequence

1. `0101-tooling.ipynb` - Course Tooling
   - Course tooling overview
2. `jupyter/0200-intro-jupyter.ipynb` - Jupyter Setup
   - Jupyter orientation
3. `jupyter/0201-python-install.ipynb` - Python installation
   - Python setup
4. `jupyter/0202-virtual-env.ipynb` - Virtual Environment
   - Environment setup and activation
5. `jupyter/0203-the-notebook.ipynb` - Jupyter Notebook
   - Notebook interface and workflow
6. `jupyter/0204-jupyter-bonus.ipynb` - Launch Jupyter FAST!
   - Faster launch workflow
